# 🍧 Dolce Moment – El Momento Dulce que Te Mereces

> Aplicación web moderna e interactiva diseñada para un emprendimiento artesanal de helados bolis en la República Dominicana.

🔗 **Demo en vivo:** [https://leafy-baklava-5e038e.netlify.app/](https://leafy-baklava-5e038e.netlify.app/)

---

## 💡 Sobre el Proyecto

**Dolce Moment** nació de una necesidad real en el mercado local: ofrecer un producto artesanal, fresco y de alta calidad con una experiencia de compra digital fluida y atractiva. Este proyecto fue concebido para fusionar los sabores del Caribe con un diseño web estético, cálido y funcional.

La página no solo sirve como catálogo visual de sabores, sino que integra herramientas interactivas reales para los clientes.

---

## ✨ Características Principales

* **🛒 Carrito de Compras Dinámico:** Permite seleccionar sabores, ajustar cantidades en tiempo real y calcular el total automáticamente.
* **💬 Integración Directa con WhatsApp:** Los pedidos y las cotizaciones para eventos especiales se envían directamente a WhatsApp con un mensaje preformateado listo para ordenar.
* **⭐ Sistema de Reseñas Interactivo:** Los usuarios pueden dejar sus valoraciones con estrellas y comentarios que se añaden visualmente al instante.
* **🎨 Diseño 100% Responsivo y Estético:** Cuidado artesanal de la UI utilizando *Glassmorphism*, paletas de colores cálidas (cremas, corales y mentas), tipografías elegantes (*Great Vibes* y *Cormorant Garamond*) y animaciones fluidas con CSS puro.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5 Semantic** (Estructura limpia y accesible).
* **CSS3 Moderno** (Variables CSS, Flexbox, Grid, Animaciones y Keyframes personalizados).
* **JavaScript (ES6+)** (Manipulación del DOM, gestión de estados del carrito y lógica interactiva de reseñas).
